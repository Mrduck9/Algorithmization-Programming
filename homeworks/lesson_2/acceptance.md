**1. T(n) — как растёт число операций с ростом числа визитов. Назовите, какие именно операции вы считали.**
1. Группировка по часам: список `visits` проходится один раз — O(n). Поиск по словарю занимает O(1), так как доступ осуществляется по ключу. Добавление через `append` — O(1).
2. Сортировка: O(n log n).
3. Цикл по `breeds` выполняется q раз, где q меньше n.
Итог: O(n log n) + O(n) = O(n log n) в худшем случае.

**2. S(n) — сколько памяти функция занимает дополнительно ко входу.** 
Формируется новый словарь (структура данных), в который заносятся все породы — O(n) по памяти.

**3. Худший случай: при каком журнале работы больше всего и почему** 
По времени: O(n log n) — в ситуации, когда все часы визитов уникальны и расположены в случайном порядке, требуется сортировка всего списка.
